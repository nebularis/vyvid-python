# Vyvid Python Domain

Вивід: домен програмування мовою Python

This domain holds notes on what can be known about Python code without running it, kept so that any project can use them. It has one register.

- `notes.md` holds one note `NOTE-n` per finding, on `tree-sitter-python` and `ast` as symbol extraction meets them, on the structural indexes `jedi` and `scip-python`, and on the `uv` behaviour that decides whether a clone's code runs. A note says what to do and why, and its Evidence cell says what was run and on which version.

A note holds for the versions and the platform it names and no others, until it is run again. A project keeps a register of the same type in its own documents and names a note of this domain in its Specialises column, so a question asked in that project is answered with the project's row first and the note beneath it. How `uv` and `mise` work in general is in the Tools domain.
