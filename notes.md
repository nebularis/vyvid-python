# Note register

**Unit type:** Register

A note says what a parse, `ast` or an index of Python code can and cannot tell without running it. Each one was measured or run, and its Evidence cell says what was run and on which version. A note holds for the versions it names and for the platform it was run on, until it is run again. A project may keep a register of the same type and name one of these rows in its Specialises column.
